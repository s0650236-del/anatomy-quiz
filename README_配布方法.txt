人体の構造と機能｜試験対策クイズ Webアプリ版

■ 推奨する学生への配布方法
このフォルダ一式をHTTPS対応のWebサーバーに置き、index.htmlのURLを学生へ配布してください。
GitHub Pagesなどの静的ホスティングで利用できます。

■ iPhone / iPad
1. 配布URLをSafariで開く
2. 共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
以後、ホーム画面からアプリのように起動できます。

■ 収録内容
元HTMLの214問をそのまま収録しています。
総論40問、循環器64問、呼吸器57問、腎・泌尿器・生殖器53問。

■ 主な機能
・章別出題
・10/20/30/50/全問
・ランダム/順番どおり
・選択肢のランダム化
・即時採点と解説表示
・結果表示
・間違えた問題だけ再挑戦
・間違えた問題の一覧確認
・iPhone/iPadのホーム画面追加
・Service Workerによるオフライン利用（初回アクセス後）

※ HTMLファイル単体をメール等で直接配布して開かせる方式は、iOS/iPadOSでは安定しないため推奨しません。
