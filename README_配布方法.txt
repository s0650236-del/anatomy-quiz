人体の構造と機能｜試験対策クイズ v2　配布方法

■ 学生への配布方法（基本）
このアプリは、HTMLファイルを直接メール添付等で配ってfile://で開く方式ではなく、
GitHub PagesのHTTPS URLを配布し、Safari等のブラウザで開いてもらう方式を基本とします。

学生には次のURLだけを伝えてください（実際のURLはリポジトリのGitHub Pages設定に応じて置き換えてください）。
  例）https://<ユーザー名またはOrganization名>.github.io/anatomy-quiz/

教員側の準備：
1. このリポジトリの v2-development ブランチの内容を main ブランチへ反映する
   （またはGitHub Pagesの公開ブランチを v2-development に設定する）。
2. リポジトリの Settings → Pages で GitHub Pages を有効化し、公開されたURLを確認する。
3. 学生へそのURLを共有する（授業支援システム、学内ポータル、メール本文へのリンク記載など）。
   ※ HTMLファイル自体を添付して送る方法は推奨しません。iOS/iPadOSではfile://からの
     JSON読み込みが制限される場合があり、正しく動作しないことがあります。

■ iPhone / iPad での使い方
1. 配布されたURLをSafariで開く
2. 共有ボタン（□に↑の矢印）をタップ
3. 「ホーム画面に追加」を選ぶ
以後はホーム画面のアイコンから、アプリのように起動できます。
一度開いた後は、電波が悪い環境や機内モードでもある程度利用できます（Service Workerによるオフラインキャッシュ）。

■ Windows / Mac での使い方
配布されたURLを Chrome / Edge / Safari 等の一般的なブラウザで開くだけで利用できます。
特別なインストール作業は不要です。

■ 収録内容（初版）
・総論・循環器・呼吸器・泌尿器の4分野、計50問
・通常の四択問題（text_mcq）と、画像を使った四択問題（image_mcq、17問）を収録
・画像問題のうち、まだ画像ファイルが用意されていない設問は「画像準備中」と表示されますが、
  文章だけでも解答・採点・解説の確認ができます。
・今後、同じ4分野を中心に約300問まで問題を追加予定です（アプリ側の操作方法は変わりません）。

■ 主な機能
・分野別出題（総論／循環器／呼吸器／泌尿器）
・全分野からのランダム出題
・出題数の選択（問題数に応じて選べる件数が自動的に変わります）
・出題順（ランダム／順番どおり）の選択
・回答直後の正誤表示と解説表示
・画像問題は画像をタップ／クリックすると拡大表示できます
・間違えた問題だけを復習する機能
・分野別の正答率表示（今回の結果、および端末に保存された累計）
・学習履歴は端末内（ブラウザのlocalStorage）に保存され、リセットも可能です
・キーボード操作にも対応（数字キーで選択肢を選ぶ、Enterで次の問題へ進む、Escで画像拡大を閉じる）

■ 学習履歴について
学習履歴は学生個人の端末（ブラウザ）内にのみ保存され、教員側のサーバーには送信されません。
ブラウザのデータを消去した場合や別の端末・別のブラウザで開いた場合、履歴は引き継がれません。

■ 注意事項
・HTMLファイル単体をメール等で直接配布して file:// で開かせる方式は、iOS/iPadOSで
  問題データの読み込みが安定しないため推奨しません。必ずGitHub PagesのURLを利用してください。
・通信環境が悪く問題データの読み込みに失敗した場合は、画面上にエラーメッセージが表示されます。
  その場合はページを再読み込みするか、通信環境の良い場所で再度お試しください（アプリ自体が
  クラッシュすることはありません）。
