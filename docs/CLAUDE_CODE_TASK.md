# Claude Code 実装依頼：人体の構造と機能A クイズ v2

## 目的
既存の「人体の構造と機能_クイズアプリv1.00.01.html」を、看護学科1年生が iPhone / iPad / Windows / Mac の主要ブラウザで学習できるクイズアプリへ改修する。

今回の初版問題データは `questions_v1.json` の50問。
最終的には約300問まで増やす予定のため、問題追加時にアプリ本体の修正が最小限で済む構造にする。

## 重要
作業前に既存HTMLを調査し、iPhone/iPadで利用できなかった原因を特定すること。
元ファイルは削除・上書きせず、改修版を別ファイルとして作成すること。

## 問題データ
- `questions_v1.json` をマスターデータとする。
- `questions.schema.json` を使ってデータ構造を検証可能にする。
- type:
  - `text_mcq` = 通常四択
  - `image_mcq` = 画像四択
- difficulty:
  - 1 = 基礎
  - 2 = 標準
  - 3 = 応用
- 画像問題は `image.asset` のパスを使用する。

## iPhone / iPad 対応上の注意
ローカルの `file://` から外部JSONを `fetch()` する設計は Safari 等で制限される可能性がある。
そのため、開発用のマスターは `questions_v1.json` として維持しつつ、配布版では以下のいずれかの方法で問題データを同梱すること。

推奨順：
1. build時にJSONをJavaScriptへ変換し、配布HTMLへインライン化する
2. `<script type="application/json" id="question-data">` としてHTML内に埋め込む
3. Webサーバー/PWA運用を採用する場合のみ外部JSON fetchを使用する

最初の配布版は「単一HTMLを開くだけでも動作する」ことを優先する。

## UI要件
- スマートフォン縦画面を基準にレスポンシブ対応
- iPhone Safari / iPad Safariで操作可能
- 選択肢ボタンはタップしやすい大きさ
- 画像問題では画像をタップして拡大表示可能
- 拡大表示後、元の問題画面へ容易に戻れる
- 1問回答後に正誤と解説を表示
- 「次の問題」ボタンで進む
- 分野別に問題を選択可能
  - 総論
  - 循環器
  - 呼吸器
  - 泌尿器
- 全分野ランダム出題
- 間違えた問題のみ復習
- 正答率を分野別に表示
- 学習履歴は端末内保存（localStorage等）を基本とする
- 履歴をリセットできる

## 画像問題
画像自体には問題番号や①等を焼き込まない。
`image.marker_target` に従い、HTML/CSS/SVGでマーカーを重ねる設計を優先する。
画像生成後に位置調整が必要なため、マーカー位置はデータ側で後から設定できるよう拡張可能にする。

例：
```json
"overlay": {
  "x": 0.42,
  "y": 0.63,
  "label": "①"
}
```
x,yは画像左上を0,0、右下を1,1とする正規化座標とする。

## 画像が未作成の場合
画像ファイルが存在しない問題はクラッシュさせず、
「画像準備中」と表示して他の問題は利用できるようにする。

## 将来300問への拡張
- 問題IDは Q001 形式を維持し、Q300以上にも対応できること
- category / subcategory / tags / difficulty でフィルタ可能
- 問題数をコード内に固定しない
- 新しい問題形式を追加できる構造にする
- 問題データと画面ロジックを分離する

## アクセシビリティ
- 選択肢を色だけで区別しない
- 画像には alt を設定
- キーボード操作も可能な範囲で対応
- 文字サイズを固定しすぎない

## 完了時に報告する内容
1. iPhone/iPadで利用しにくかった原因
2. 作成・変更したファイル一覧
3. データ読み込み方式
4. 実装した機能
5. iPhone/iPadでの確認方法
6. 未実装または制約事項
7. 300問へ増やす手順
8. 問題を1問追加する具体例

## 禁止
- 元ファイルの削除
- 教科書画像の転載は禁止コピー
- 不要な外部ライブラリの大量導入
- ネット接続を必須にすること
- 画像未配置を理由にアプリ全体が動かなくなる実装
