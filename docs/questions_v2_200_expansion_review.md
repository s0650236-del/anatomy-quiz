# v2 200問拡張レビュー資料（Q101〜Q200候補）

anatomy-quiz を100問から200問へ拡張するための候補100問（Q101〜Q200）の設計資料。
最終的に約300問体制を想定し、看護学部1年次の「人体の構造と機能」として現在ほぼ存在しない重要領域（消化器・神経系・運動器・内分泌）への進出を優先した設計としている。

**本資料は設計・レビュー用のドキュメントであり、`data/questions_v1.json` へはまだ何も追加していない。** 実装は本資料のレビュー後、別途進める。

- 基準HEAD: `485c89d1f703a50f75be8bfe3d86eb4a7dc87830`（branch: v2-development）
- 候補数: 100問（Q101〜Q200、欠落・重複なし）
- 画像生成パイプライン（`tools/image_generation/`）・APIキー設定・実際の画像生成は今回のスコープ外。本資料で設計したimage_mcqは、将来manifestへ追加できる仕様として記載するにとどめる。既存の未生成15 unique assetにも変更を加えていない。

## 3. Q101〜Q200の領域配分（決定）

| category | 問題数 | 採用理由 |
|---|---|---|
| 総論 | 8 | 運動器（筋組織）・神経系（神経組織）の土台となる細胞・基本組織・恒常性の概念を補完。既存4領域の大量追加は避け、必要最小限にとどめた。 |
| 消化器 | 26 | 看護学教育で必須の大規模系統。臓器数が多く、口腔から肛門までの消化管および肝臓・胆嚢・膵臓の付属器官を扱う必要があるため、4新領域中で運動器と並び最大級の配分とした。 |
| 神経系 | 28 | 臨床科目（成人看護学・老年看護学等）との接続が最も強く、複雑さ・重要性ともに最高水準のため、4新領域中最大の配分とした。 |
| 運動器 | 24 | 骨・関節・筋という named structure（名称を要する構造）が非常に多いため、内分泌より手厚い配分とした。 |
| 内分泌 | 14 | 腺そのものの数は少なく、神経系・消化器ほどの構造的複雑性はないため、4新領域中では最小の配分とした。ただし300問版でさらに8問を追加し、最終的には運動器に次ぐ規模を確保する。 |
| **計** | **100** | |

生殖器・血液免疫・感覚器は、今回200問段階では**導入しない**方針とした。理由：

1. 生殖器は旧214問に素材（L178〜L200、23問相当）が存在するが、消化器・神経系・運動器・内分泌という「現在ゼロの重要4領域」を優先することが看護学教育上のカバレッジ拡大に直結する。生殖器は母性看護学等の専門科目と重なる部分が大きく、300問版でまとめて体系的に扱う方が教育設計として一貫する。
2. 血液・免疫、感覚器は旧214問に素材が存在せず、全問新規作成が必要になる点は消化器等と同条件だが、内分泌（Q187〜Q200）に比べて他の新設4領域との接続点（例：血液は循環器と、感覚器は神経系と密接）が薄く、200問版でこれらを扱うより、先に神経系・内分泌の基礎を固めたうえで300問版に回す方が学習順序として自然と判断した。

## 4. 各領域の学習目標

### 総論（細胞・組織、Q101〜Q108）

- 細胞の基本構造（細胞膜・細胞質・核）を説明できる
- 代表的な細胞小器官（特にミトコンドリア）の役割を理解する
- 上皮組織・結合組織の分類の視点を追加で理解する
- 筋組織の3分類（骨格筋・心筋・平滑筋）を区別できる
- 神経組織の基本単位（ニューロン）とそれを支持するグリア細胞を理解する
- 恒常性（ホメオスタシス）の概念を説明できる

### 消化器（Q109〜Q134）

- 消化管を通る順序（口腔→咽頭→食道→胃→小腸→大腸→肛門）を説明できる
- 口腔・咽頭・食道の構造と嚥下の3過程を理解する
- 胃の位置・構造（噴門・幽門・大彎・小彎）を説明できる
- 小腸の3区分（十二指腸・空腸・回腸）と吸収機能（絨毛）を理解する
- 大腸の区分（盲腸・結腸・直腸）と主な機能（水分吸収）を説明できる
- 肝臓・胆嚢・膵臓の位置と機能（代謝・解毒・胆汁生成／貯蔵・濃縮／消化酵素分泌）を理解する
- 膵臓が外分泌・内分泌の両機能をもつことを理解する
- 主な消化酵素と対象栄養素、三大栄養素の最終消化産物を対応づけられる
- 門脈系・腹膜・消化管壁の4層構造という横断的な視点を理解する

### 神経系（Q135〜Q162）

- 中枢神経系・末梢神経系の大区分を説明できる
- ニューロンの基本構造と興奮伝導の方向、シナプスでの情報伝達を理解する
- 大脳の4脳葉と機能局在の基礎（運動野・感覚野）を理解する
- 間脳（視床・視床下部）・脳幹（中脳・橋・延髄）・小脳の位置と機能を説明できる
- 髄膜の3層構造と脳脊髄液の役割を理解する
- 脊髄の位置・構成（灰白質・白質、前根・後根）と脊髄神経・脳神経の対数を理解する
- 反射弓の基本構成を説明できる
- 体性神経系と自律神経系（交感神経・副交感神経の二重支配・拮抗作用）を区別できる

### 運動器（Q163〜Q186）

- 骨格系の主な機能（支持・保護・運動・造血・カルシウム貯蔵）を説明できる
- 骨の形態分類・構造（骨膜・骨質・骨髄）・成長（骨端線）・リモデリングを理解する
- 頭蓋骨・脊柱・胸郭・上肢骨・下肢骨・骨盤という全身骨格の主要構成を位置づけられる
- 関節の可動性による分類と、可動関節の基本構造（関節包・滑液・関節軟骨）を理解する
- 骨格筋の基本構造・収縮の仕組み・神経支配（神経筋接合部）を理解する
- 筋の起始・停止という概念を用いて、代表的な体幹・上肢・下肢の筋の作用を説明できる

### 内分泌（Q187〜Q200）

- 内分泌腺と外分泌腺の違いを説明できる
- 下垂体（前葉・後葉）・甲状腺・副甲状腺・副腎（皮質・髄質）の位置と代表的ホルモンを理解する
- 膵島（インスリン・グルカゴン）による血糖調節の基礎を理解する
- 内分泌系における負のフィードバック機構の概念を理解する
- 性腺が生殖細胞の産生に加え内分泌機能をもつことを理解する（詳細な生殖器解剖は300問版で扱う）

## 14. 今後の実装順序

1. 本資料（第2版に相当する初版）について教員レビューを受ける。
2. レビュー結果を反映した修正版を作成する（Q051〜Q100の際と同様の手順）。
3. `data/questions.schema.json` の `category` enumに `消化器`・`神経系`・`運動器`・`内分泌` を追加する（現在は `総論`・`循環器`・`呼吸器`・`泌尿器` の4値のみに限定されているため、Q101〜Q200を実装する前に必須の準備作業）。
4. `data/questions_v1.json` へQ101〜Q200を追加し、`question_count` を200へ更新する。
5. 100問→200問の際に実施したものと同様のデータ監査（ID欠落・重複なし、choices/answer整合、JSON parse等）を実施する。
6. 画像未生成のimage_mcqについては、既存アプリのプレースホルダー機構を利用してデータのみ実装する（画像生成は別途、APIキー設定後に着手）。
7. 100/200問レベルでのアプリ回帰テスト（PC/iPad/smartphone、正答判定、履歴、間違い問題復習）を実施する。
8. 検証済みのデータのみをcommitし、`origin/v2-development` へpushする。
9. 画像生成パイプライン（`tools/image_generation/`）にAPIキーが設定され次第、本資料で設計した12種類のunique assetの生成に着手する。
10. 200問版が安定した後、Q201〜Q300（生殖器・感覚器・血液免疫を中心とする300問版）の設計に着手する。
