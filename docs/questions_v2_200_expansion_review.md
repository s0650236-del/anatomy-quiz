# v2 200問拡張レビュー資料（Q101〜Q200候補）〔対象領域限定版〕

anatomy-quiz を100問から200問へ拡張するための候補100問（Q101〜Q200）の設計資料。

**このアプリの対象範囲は、総論・循環器・呼吸器・泌尿器の4領域のみである。** 消化器・神経系・運動器・内分泌・感覚器・血液免疫・生殖器などは、このアプリの担当範囲外であり、今回の候補には一切含まれていない。前バージョン（初版、消化器・神経系・運動器・内分泌をQ101〜Q200に含む設計）は方針の誤りであったため全面的に破棄し、本資料はその置き換えである。

**本資料は設計・レビュー用のドキュメントであり、`data/questions_v1.json` へはまだ何も追加していない。** 実装は本資料のレビュー後、別途進める。

- 基準HEAD: `52770ac3ba62d44f957c3775865ad02a577c4902`（branch: v2-development）
- 候補数: 100問（Q101〜Q200、欠落・重複なし）、すべて総論・循環器・呼吸器・泌尿器のいずれか
- 画像生成パイプライン（`tools/image_generation/`）・APIキー設定・実際の画像生成は今回のスコープ外。本資料で設計したimage_mcqは、将来manifestへ追加できる仕様として記載するにとどめる。既存の未生成15 unique assetにも変更を加えていない。

## 1. このアプリの対象範囲

このアプリ（anatomy-quiz）が扱う「人体の構造と機能」の担当範囲は、以下の4領域に限定される。

| 領域 | 内容の骨子 |
|---|---|
| 総論 | 人体の基本構造・細胞・組織・体腔・方向用語・人体の面など |
| 循環器 | 心臓・血管・体循環／肺循環・冠循環・刺激伝導系・心電図・心周期・血圧・血流など、循環器系の構造と基本生理 |
| 呼吸器 | 上気道・下気道・喉頭・気管／気管支・肺・肺胞・導気部／呼吸部・換気・ガス交換・呼吸調節など、呼吸器系の構造と基本生理 |
| 泌尿器 | 腎臓・ネフロン・腎小体・尿細管・尿生成・腎血流・腎機能・尿管・膀胱・尿道・蓄尿／排尿など、泌尿器系の構造と基本生理 |

**生殖器はこのアプリには含めない。** 消化器・神経系・運動器・内分泌・感覚器・血液免疫も同様に対象外である。最終的に200〜300問へ拡張する場合も、この4領域だけを深めることを基本方針とする。
