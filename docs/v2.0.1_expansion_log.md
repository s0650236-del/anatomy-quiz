# v2.0.1 image_mcq拡張記録（asset-first）

既存の高品質asset（前フェーズでOPEN素材へ差し替え済みのものを中心に）を起点に、「この画像から教育的に成立する問題を何問作れるか」を全28assetについて再検討し、実際に11問のimage_mcq（Q301〜Q311）を追加実装した記録。

**方針**：asset first → 画像上で一意にmarker可能な構造を列挙 → 既存300問との重複確認 → 看護1年生向けの教育的重要性でフィルタ → 実装。新規OPEN素材の追加探索は行っていない（既存28asset内で完結）。

---

## Phase 1〜2：全28asset確認・markable構造の洗い出し（要約）

全28assetを確認した結果、以下のassetで**画像上に実際に描出されているが、まだどの問題からもmarkされていない構造**を発見した。それ以外のasset（`q021_vessel_cross_sections`／`q068_ecg_waveform`／`q017_heart_chambers`／`q037_alveolar_gas_exchange`／`q035_right_middle_lobe`／`q040_airway_branching`／`q008_body_planes`／`direction_terms`／`pleura_cross_section`／`heart_valve_plane`／`circulation_circuit`／`q002_hierarchy`／`q004_epithelium`／`q016_apex`／`anatomical_position`／`heart_valves_schematic`／`q045_renal_hilum`）は、既存markerで画像内の主要構造がほぬ使い切られている、または追加すると過度に細かい専門解剖になる（初学者範囲を超える）と判断し、今回は追加していない。

## 検討したが不採用にした候補

- **`q050_urinary_system.webp`の尿道**：膀胱下端に小さく描かれた分岐状の構造が尿道を示すと解釈できなくもないが、視覚的に小さく・形状が曖昧で「markerが一意に構造へ着地する」という基準を満たせないと判断し、見送った。
- **`q073_coronary_arteries.webp`の上行大動脈**：`heart_exterior_anterior.webp`のQ301（肺動脈幹）と教育的に重複する大血管識別のため、二重出題を避けて見送った。
- **`q017_heart_chambers.webp`・`q037_alveolar_gas_exchange.webp`への追加**：すでに4問・2問が高い密度で構造をカバーしており、これ以上の追加は初学者範囲を超える細分化（腱索の個別部位、肺胞上皮細胞のサブタイプ等）になると判断し見送った。
