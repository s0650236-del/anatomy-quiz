## 分類の凡例

各問題には以下のいずれか（複数可）のタグを付与している。

| タグ | 意味 |
|---|---|
| **A** | そのまま移植可能（文言・出題形式ともに変更不要） |
| **B** | 表記のみ修正（v2の文体・用語表記への統一が必要だが、text_mcqのまま） |
| **C** | text_mcq → image_mcq へ出題形式を変更 |
| **D** | （Cのうち）新規画像の生成が必要 |
| **E** | 教員確認後でないと採用できない（Q028の分類方針に連動） |
