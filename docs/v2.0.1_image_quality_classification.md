# v2.0.1 画像問題 教育的品質改善フェーズ：全28 asset の再分類

「画像問題数を増やすことではなく、既存画像assetの教育的品質を改善する」という今回のフェーズの目的に沿って、既存の全28 unique assetを再レビューし、**Accept（現状で教育的に妥当）／Replace now（今回差し替え）／Later（改善余地はあるが致命的ではなく、次フェーズ以降の課題）**の3分類を行った結果。

判断基準：**「図を見ただけで、その構造の基本的な形・位置関係・（複数構造の比較であれば）違いが、看護1年生の目線で理解できるか」**。単なる見た目の綺麗さではなく、この基準を満たさない、または致命的に誤解を招く抽象化になっている場合のみ Replace now とした。

## Later（7 asset）

いずれも「意味不明」「誤解を招く」水準ではなく、構造の位置関係は理解できるレベルにあるが、実写素材への置き換えでさらに質を上げる余地がある、または今回のオープンライセンス探索では直接一致する適切な代替が見つからなかったもの。次フェーズ以降の課題として明記し、今回は見送った（致命的な破綻がないことを確認した上での意図的な先送り）。

| asset | 現状 | 見送り理由 |
|---|---|---|
| `q008_body_planes.webp` | 人体シルエット＋3断面（矢状面・冠状面・水平面）の模式図 | 面の位置関係自体は模式図で十分伝わる。断面の「向き」がテーマであり、人体シルエットの写実性は本質ではない |
| `q016_apex.webp` | 心尖の位置を示す模式図 | 位置関係（心尖の向き）は明瞭。実写化しても教育的な追加情報は少ない |
| `q035_right_middle_lobe.webp` | 肺葉の模式図 | 肺葉の区分・位置関係は模式図で明瞭。Servier素材に直接一致する候補が見つからなかった |
