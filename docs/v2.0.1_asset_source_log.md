# v2.0.1 画像差し替え記録（実施結果）

Sランク10assetのうち9件、Bランク3assetを、実際にオープンライセンス素材で高品質画像へ差し替えた実施記録（合計12asset差し替え／新規追加）。方針・brief仕様は[docs/v2.0.1_image_replacement_brief.md](v2.0.1_image_replacement_brief.md)を参照。本ファイルは「実際に何を・どこから・どのライセンスで取得し、どのQIDに適用したか」の再現可能な記録。

**画像先行の結果、当初の想定（brief作成時点でのSVG-PRO/OPEN/AI分類）よりOPEN素材で解決できた範囲が大きかった**。特にAnatomyTOOL.org（Servier Medical Artの「no labels」版を再配布するCC BY 4.0リポジトリ）から、文字ラベルなしの高品質画像を複数発見できたため、当初AI生成予定だった`q025_conduction_system`と`q091_kidney_cross_section`もOPEN素材で解決した。

## 画像処理

全ファイル共通：透過PNG→白背景へ合成（既存`svg_to_webp.py`と同じ方式）、長辺1600pxを目安にリサイズ、WebP変換（quality=92）。`q091_kidney_cross_section.webp`のみ、原画像が両側腎臓のペア画像だったため片側（1腎）をトリミングして単一腎臓の断面図とした。`q045_renal_hilum.webp`のみ、原画像解像度が低かったため長辺1600pxへアップスケール（ベクター調のフラットカラー画像のため画質劣化は視認上問題なし）。

## 今回のスコープ判断

- **image_mcq拡張（優先度2）は今回も実施していない。** 「数を増やすことより教材としての質を優先」という判断基準に従い、Sランク10asset中9assetの高品質差し替え、Bランク3assetの追加差し替え、Q140の誠実な処理（近似marker禁止への対応）、sequential mode修正、Credits整備を丁寧に完了することを優先した。オープン素材収集の過程で他の高品質image_mcq候補も見つかっているが、教育的重複・難易度バランスの検討まで含めた設計は次フェーズで改めて行うべきと判断し、今回は着手していない。
- **Bランク改善は3asset（heart_valve_plane新規／q041_alveolar_sac／q073_coronary_arteries）のみ実施。** `q008_body_planes`／`q016_apex`／`q021_vessel_cross_sections`／`q035_right_middle_lobe`／`q040_airway_branching`／`anatomical_position`／`direction_terms`／`pleura_cross_section`は、Servier Medical Art単独では直接一致する適切な代替が見つからなかった（`q021_vessel_cross_sections`は現行の同心円比較図が模式図として教科書的にも妥当と判断し維持）ため今回は見送った。SVG-PROとして許容される範囲のものであり、教材として明確な破綻はない。

## 残課題

1. **`q011_germ_layers.webp`が未解決（AI_MANUAL_REQUIRED）。** Servier Medical Artのembryologyカテゴリ（3ページ全件確認）に該当画像なし。OpenStax由来の画像（オランダ語版・英語版〈fig.28.9〉の両方をAnatomyTOOL/Wikimedia Commonsで確認）はいずれもラベル文字・引き出し線が画像へ直接焼き込まれており、トリミングでも除去できなかったため不採用。SVGでの粗雑な模式化も過去に誤解を招いた実例があるため見送り。[docs/v2.0.1_image_replacement_brief.md](v2.0.1_image_replacement_brief.md)内に既存のAI生成brief仕様を用いて、次回改めてAI画像生成を検討する必要がある。
2. **Q140は`text_mcq`化により解決済み。** 冠状静脈洞の近似markerは使用していない（詳細は上記dataset側の変更）。
3. **心臓後面図の複数QID共有について**：`heart_exterior_posterior.webp`はQ019/Q125の2問で共有する設計とした（Q140は本フェーズでtext_mcq化されたため対象から外れた）。`?review=assets`で確認済み。
