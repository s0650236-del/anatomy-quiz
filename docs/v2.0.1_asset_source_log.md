## 今回のスコープ判断

- **image_mcq拡張（優先度2）は今回も実施していない。** 「数を増やすことより教材としての質を優先」という判断基準に従い、Sランク10asset中9assetの高品質差し替え、Bランク3assetの追加差し替え、Q140の誠実な処理（近似marker禁止への対応）、sequential mode修正、Credits整備を丁寧に完了することを優先した。オープン素材収集の過程で他の高品質image_mcq候補も見つかっているが、教育的重複・難易度バランスの検討まで含めた設計は次フェーズで改めて行うべきと判断し、今回は着手していない。
- **Bランク改善は3asset（heart_valve_plane新規／q041_alveolar_sac／q073_coronary_arteries）のみ実施。** `q008_body_planes`／`q016_apex`／`q021_vessel_cross_sections`／`q035_right_middle_lobe`／`q040_airway_branching`／`anatomical_position`／`direction_terms`／`pleura_cross_section`は、Servier Medical Art単独では直接一致する適切な代替が見つからなかった（`q021_vessel_cross_sections`は現行の同心円比較図が模式図として教科書的にも妥当と判断し維持）ため今回は見送った。SVG-PROとして許容される範囲のものであり、教材として明確な破綻はない。
