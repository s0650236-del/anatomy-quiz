# v2 300問拡張レビュー資料（Q201〜Q300候補）

anatomy-quiz を200問から300問へ拡張するための候補100問（Q201〜Q300）の設計資料。

**このアプリの対象範囲は、総論・循環器・呼吸器・泌尿器の4領域のみである。** 消化器・神経系・運動器・内分泌・感覚器・血液免疫・生殖器はこのアプリの担当範囲外であり、今回の候補にも一切含まれていない。ただし、循環器・呼吸器・泌尿器の正常生理を説明するために必要な自律神経やホルモン等の関連知識は、当該領域の一部として必要最小限扱っている（神経系・内分泌系そのものの各論には立ち入らない）。

**本資料は設計・レビュー用のドキュメントであり、`data/questions_v1.json` へはまだ何も追加していない。** Q101〜Q200（`docs/questions_v2_200_expansion_review.md`）も今回は変更していない。300問全体の設計が揃った段階で、まとめて教員レビューを行う想定である。

- 基準HEAD: `6134f74d46cbdb416e167f81f2af53cad20f78a9`（branch: v2-development）
- 候補数: 100問（Q201〜Q300、欠落・重複なし）、すべて総論・循環器・呼吸器・泌尿器のいずれか
- 画像生成パイプライン・APIキー設定・実際の画像生成は今回のスコープ外。

## 1. このアプリの対象範囲

総論・循環器・呼吸器・泌尿器の4領域に限定される（前回資料と同一方針）。生殖器・消化器・神経系・運動器・内分泌・感覚器・血液免疫は対象外。

## 5. 各領域の追加方針

### 総論
細胞の輸送様式（拡散・能動輸送・浸透）、上皮・結合組織・筋組織の機能的まとめ、興奮性という筋組織・神経組織の共通性質、漿膜（心膜・胸膜の上位概念）、体液の酸塩基平衡・電解質、恒常性の統合。神経系各論・運動器各論・免疫学各論・血液学各論へは発展させていない。

### 循環器
後負荷、末梢血管抵抗・微小循環、心臓の隔壁（心室中隔・心房中隔）、心臓弁の位置関係統合（僧帽弁・大動脈弁を新設し既存の三尖弁・肺動脈弁と対にする）、冠循環の統合（冠状静脈洞・洞房結節への血液供給）、血圧の詳細（脈圧・平均血圧・圧受容器）、刺激伝導系の視覚的統合。病態・治療（不整脈・心筋梗塞の診断等）は一切扱っていない。

### 呼吸器
上気道の残り（鼻中隔・副鼻腔・声帯・喉頭蓋）、気管の構造・気管分岐部、肺門・気管支動脈という循環器との接点、肺コンプライアンス・気道抵抗・換気血流比という力学分野、呼吸筋の神経支配のまとめ。肺区域番号や内喉頭筋等の過剰な局所解剖は採用していない。

### 泌尿器
腎臓の被膜・内部構造の残り（腎筋膜・腎柱・腎杯の階層）、傍糸球体装置・GFR・対向流増幅系というネフロン生理の発展、内尿道括約筋・排尿筋という構造の明示、電解質・酸塩基平衡の統合、泌尿器系全体および4領域全体のまとめ。内分泌学全体・骨代謝・生殖器へは拡張していない。
